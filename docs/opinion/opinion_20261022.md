# reply.py 最小MVPの返信境界

日付: 2026-10-22

## 目的

動く最小MVPの骨組みを先に作る。返信の言い回しや記憶の選び方は、後から肉付けする。

`reply()` は、最終的な返信文字列を返す関数のままにする。記憶の整理と、語句の選択は、その手前の別関数に分ける。

完成時の契約は次のとおり。

> ユーザー名・現在の発言・任意の関連記憶1件を受け取り、決定論的な返信本文を返す。

同じ発言と同じ記憶には、常に同じ文字列を返す。`reply.py` は標準入出力、状態遷移、記憶の保存、記憶の検索を行わない。

## 関数の役割

| 関数 | 受け取るもの | 返すもの |
|---|---|---|
| `reply_remember` | 外から渡された記憶1件、または `None` | 使う記憶の文字列、または `None` |
| `reply_phrase` | 今の発言 | 選ばれた返信本文、または `None` |
| `reply` | 発言、ユーザー名、`remember` | いつも文字列の返信 |

呼び出しの形は次のとおり。

    remember = reply_remember(memory)
    text = reply(request, user_name, remember)

`remember` は `reply()` の第3引数である。`reply_remember()` の戻り値を、そこに渡す。

`on_thinking()` は、まだ記憶を選ばない。`reply_remember(None)` の結果を渡す。状態は `LISTENING → THINKING → SPEAKING → IDLE` のままである。`reply()` は `THINKING` で1回だけ呼ばれる。

## 記憶

`reply_remember` が見るのは、今の発言ではない。呼び出し側が渡した1件である。

| 渡された値 | 戻り値 |
|---|---|
| `None` | `None` |
| `""` | `None` |
| `"来週、発表がある"` | `"来週、発表がある"` |

空文字は記憶なしと同じにする。前に空白だけが付き、今の返信と文字列が変わるのを避けるためである。

この関数は、どの記憶を思い出すかを決めない。渡された1件を、使う文言か `None` かに整えるだけである。

## 語句

単発の発言も、複数語句を含む発言も、`reply_phrase()` が受ける。登録語句は次の5つである。

| 語句 | 返信 |
|---|---|
| `こんにちは` | `こんにちは!` |
| `おはよう` | `おはようございます!` |
| `こんばんは` | `こんばんは!` |
| `お疲れ様` | `お疲れ様です!` |
| `疲れた` | `ゆっくり休んでください!` |

探す前に、既存の `normalize()` で空白と句読点を除く。

語句が複数あるときは、正規化した文の中で一番左にある一つだけを選ぶ。同じ語句が二度出たときは、最初の一回だけを見る。どの語句も無ければ `None` を返す。フォールバックの文は、この関数では作らない。

| 入力 | 語句の数 | 戻り値 |
|---|---|---|
| `こんにちは` | 1 | `こんにちは!` |
| `今日は疲れた` | 1 | `ゆっくり休んでください!` |
| `こんにちは、今日は疲れた。` | 2 | `こんにちは!` |
| `関係ない文` | 0 | `None` |

`こんにちは、今日は疲れた。` では `疲れた` も見つかる。返信に使うのは、左にある `こんにちは` だけである。複数の返信を一つの文へつなぐことは、この段階では行わない。

## 返信の組み立て

`reply()` は、`reply_phrase()` の結果と、引数 `remember` を結合する。

`reply_phrase()` が `None` のとき、本文は次のフォールバックにする。

    {user_name}さん、ごめんね。もう一度聞いてくれる？

`remember` が `None` のときは、その本文だけを返す。記憶があるときは、記憶、半角スペース、本文の順にする。

| 発言 | `remember` | 戻り値 |
|---|---|---|
| `こんにちは` | `None` | `こんにちは!` |
| `疲れた` | `None` | `ゆっくり休んでください!` |
| `疲れた` | `来週、発表がある` | `来週、発表がある ゆっくり休んでください!` |
| `関係ない文` | `None` | `テストさん、ごめんね。もう一度聞いてくれる？` |

`reply()` の戻り値は、すべての経路で文字列である。`None` になるのは、記憶の値の側である。

## テスト

`tests/terminal_robot/test_reply.py` では、`今日はこんにちは` などをフォールバックと期待している。実装後の期待値は、含まれている語句の返信へ更新する。

追加で確認すること:

- `こんにちは、今日は疲れた。` が `こんにちは!` になること
- `reply_remember(None)` と `reply_remember("")` が `None` になること
- `remember` が `None` のとき、今の単体返信と同じ文字列になること
- 記憶 `来週、発表がある` が、返信の前に半角スペース1つで付くこと
- 同じ発言と同じ記憶から、同じ文字列が返ること

## この段階では扱わないもの

- 複数語句の返信を、出現順につなぐこと
- 記憶の保存、検索、順位付け
- PostgreSQL やファイルへの記録
- LLM による返信生成
- 登録語句の追加
- 記憶を置く位置や、つなぎの言い回しの変更
