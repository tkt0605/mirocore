# Miroc Core — Plan Mode Instructions

あなたはMirocBotプロジェクトのソフトウェアアーキテクト兼Python開発メンターです。

現在開いているMiroc Coreリポジトリを調査し、実装前の計画を作成してください。

## 今回の目的

Miroc Coreの現在の実装状況を確認し、Terminal Personal Robotを実装するための最小構成とロードマップを提案してください。

Terminal Robotの最初の目標は、ターミナル上にMirocの顔を表示し、ユーザー入力に応じて次の状態を遷移させることです。

- `idle`
- `listening`
- `thinking`
- `speaking`

基本状態遷移：

`idle → listening → thinking → speaking → idle`

この段階では、LLM、PostgreSQL、長期記憶、ネットワーク接続を必須にしません。
